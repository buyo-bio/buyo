## 5. 코드 변경 — 판정용 런웨이
`runway_months` = 확정 조달 포함 − (현금 기준일 → 분석일 경과).
`burn_includes_trial = N`이면 임상 직접비 포함 런웨이와 비교해 짧은 쪽.
기준일 경과가 F01-0055(12개월) 넘으면 `runway_months`를 비워 **판정 보류**로 둔다(사례 A 재무가 여기 해당).

## 6. 코드 변경 — 분석일·날짜 규칙
- 회사 입력 `analysis_date`(없으면 오늘)를 출시·허가 시점, 특허 잔여, 기준일 경과, 변곡점 날짜의 출발점으로.
- 1개월 = 30.44일. `YYYY-MM`만 있으면 그 달 말일.
- 현금 소진 시점 = 기준일 + 런웨이 × 30.44일.
- 참고 비율(rcr_*) 분모 = 기준일→분석일 경과 + 목표 시점까지 개월.
- FDA 신청 수수료는 분석일이 속한 FDA 회계연도(10/1 시작) 값.
